# vision-proxy documentation

`vp` is a CLI that sends images to a vision-capable model and returns fenced, untrusted descriptions.

## Get started

- [QUICKSTART.md](./QUICKSTART.md) — install and run your first analysis.
- [SETUP.md](./SETUP.md) — choose a provider and configure `vp`.

## Reference

- [CONFIG.md](./CONFIG.md) — full config schema, JSON examples, and environment variables.
- [providers/](./providers/) — OpenAI, Anthropic, and Google.
- [FALLBACK.md](./FALLBACK.md) — fallback model chain.
- [INTEGRATIONS.md](./INTEGRATIONS.md) — install `vp` into Claude Code, Codex, or Pi.
